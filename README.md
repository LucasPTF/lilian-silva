# Lilian Silva

Página de vendas do guia digital Ansiedade e Ataque de Pânico.

## Rotas

* `/a1`: ângulo de dor e nova saída
* `/a2`: ângulo de quebra de crença
* `/a3`: ângulo de resultado e quebra de objeção
* `/obrigado`: orientações seguras após a compra

As páginas A1, A2 e A3 usam a mesma estrutura, identidade visual, oferta e conteúdo. Apenas a hero muda entre os três caminhos.

## Uso local

1. Execute `npm run build`.
2. Execute `npm run start`.
3. Abra o endereço indicado no navegador.

## Validação

Execute `npm run validate` para conferir rotas, links principais, igualdade estrutural e caracteres proibidos.
